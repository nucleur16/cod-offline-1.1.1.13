# Button icon art

The icons in `glyphs/xelu/` (and the textures built from them into `glyphs.bin`) come from
**Xelu's FREE Controllers & Keyboard Prompts** by Nicolae "Xelu" Berbece / Those Awesome Guys,
https://thoseawesomeguys.com/prompts/ (Xelu_Free_Controller&Key_Prompts.zip,
sha256 2848fd4259437a6f594f81ff8d8d7a1f922397c7e9da163b2535aa82ae1df037).

The pack is dedicated to the public domain under Creative Commons Zero (CC0 1.0); its own readme is kept
as `xelu/Readme.txt` ("All of the assets are in the public domain under Creative Commons 0 (CC0)").
Attribution is not required; it is given here with thanks.

Used: Others/Xbox 360, Others/PS3, Others/WiiU, Others/Positional Prompts and Steam Deck (the generic set).
The "hold" icon is the pack's button with a ring added by `make_glyphs.py`.
The PNGs are unchanged copies of the pack's 100x100 exports.

## Controller diagrams

The controller diagrams in Options > Controller are original line art defined as data in
`glyphs/make_diagrams.py` (body outline points, button circles, rectangles, sticks and D-pad), written for
this project. No console maker's artwork was used. Same licence as the rest of this repository.
