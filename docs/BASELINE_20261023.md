This is the candidate baseline for continuing work. It is not a production
release approval. The remaining real-client acceptance checks stay required.

## Source of truth

Continue from this branch and its recorded baseline, including upstream
`82a06df3c134789cb021a66d62b1fd584a7036a4e`. Rebuild through
`build_zones.py`; do not substitute older English or Chinese fastfiles.
Both languages use the same frontend and in-game movies. Their language zones
contain strings, and the startup language selector chooses one set.

Retired playlists stay hidden even when Quick Match is unavailable. Development
maps, including Shi No Numa, remain excluded from shipping output.

inputs. Shipping builds and `tests/test_ui_baseline.py` reject baseline drift, stale source metadata and
language-specific functional movies. Deliberate new work uses `--candidate`
and defaults to `output_candidate/`; review and record an intentional baseline
change before producing shipping output. These checks do not replace gameplay
acceptance against the exact generated files.

The baseline retains queue timers, navigation guards, native room handling,
password behavior, difficulty controls, party ready-state handling, results
screens, and the delayed-results host-ready fix under qualification. It also
retains upstream's newer localization, FOV, controller, borderless and voice
changes. Existing launchers' `codol_patchlang en/zh` remains compatible with
the canonical `k33_english 1/0` switch.
