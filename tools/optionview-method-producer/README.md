# OptionView method-only stored producer

`python -B tools/optionview-method-producer/reproduce.py` replays the deterministic,
read-only ABC transplant from retained compiler DATA. It does not compile, launch
Java, write files, execute ABC or rebuild a movie/FF. `base.abc`, `original.tag.bin`
and `compiled-intermediate.tag.bin` are developer-only inputs outside `zones`.
Only the remapped `k33SetLabel` body is published in the stored zone tag; its
original pools, tables and other 38 bodies stay exact. The intermediate's other
bodies are discarded. The full original whole-class baseline remains HOLD.

`recipe.json` binds the fixed original/intermediate, source plus diagrams include,
reviewed pure readers/transplant and actual output tag. The original-header GFX
digest is distinct from FFDec's normalized FWS diagnostic digest. Neither digest
is FF/game/release acceptance. Generic `compile_as`/`store_class` and build-level
`--compile-as` paths refuse this target with the same dot/slash normalization
as the existing class resolver, before export/compile IO. A normal build uses the
stored tag only when the source/include digest matches; no silent recompile or
generic fallback is permitted. Other classes retain their existing routes.

The actual two-call producer and ownership/tool receipts are frozen externally;
the recipe records those packet hashes. This local tool preserves the accepted
method algorithm as source, not authorization for another compiler call.
